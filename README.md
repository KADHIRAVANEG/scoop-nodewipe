# Scoop Bucket for nodewipe

Official Scoop bucket for [nodewipe](https://github.com/KADHIRAVANEG/nodewipe) — The surgical, blazing-fast dev-environment cleaner written in Rust.

## Installation

Add this bucket to Scoop and install `nodewipe`:

```powershell
scoop bucket add nodewipe https://github.com/KADHIRAVANEG/scoop-nodewipe
scoop install nodewipe
```

### Direct Manifest Installation (Without Adding Bucket)

```powershell
scoop install https://raw.githubusercontent.com/KADHIRAVANEG/nodewipe/main/packaging/scoop/nodewipe.json
```

## Updating

```powershell
scoop update nodewipe
```

## Verification
```powershell
nodewipe --version
```
